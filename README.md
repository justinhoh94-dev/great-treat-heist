# The Great Treat Heist

**Play it here: https://justinhoh94-dev.github.io/great-treat-heist/**

A cartoony 3D puzzle game in your browser: Bagel the beagle sniffs out a snack in every room of the house, from dawn to his birthday party.

This repository only holds the published build, served by GitHub Pages from the `gh-pages` branch. It's replaced on every deploy, so don't edit it by hand.
